Supabase connection

Set your project URL and anon key at the top of app.js, then reload this page.

window.APP_CONFIG = {
  SUPABASE_URL: 'https://YOUR-PROJECT.supabase.co',
  SUPABASE_ANON_KEY: 'YOUR-ANON-KEY'
};  // ไฟล์ config.js

Also run phase2_auth_and_roles.sql in the Supabase SQL editor so login and department permissions work.

Open Monthly Cycle

Creates a draft evaluation for every active supplier that doesn't already have one for the month you pick, so each department finds it waiting instead of creating it from scratch. Safe to run again — never touches an evaluation that already exists.

Create new accounts below, or change an existing user's department/role in the table.

Toggle a checkbox to change what that department can do — takes effect immediately, enforced by the database itself (not just this screen). Be careful: removing your own department's permission here can lock you out of an action until another admin restores it.

Excluded from the Corrective Action "5 working days" due-date calculation, along with weekends. 2026 is pre-loaded with Thailand's official public holidays — add more (company-specific days off, future years) as needed.

Import from Excel

Upload one or more monthly FM0704-3 evaluation files. Every supplier sheet is parsed and matched to an existing supplier where possible — nothing is written until you review the preview below and confirm.

Export to Excel

Exporting works from the Evaluation List — tick the suppliers/months you want (only itemized evaluations can be exported), then click "Export Selected" there.
